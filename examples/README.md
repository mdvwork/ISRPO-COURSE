# Демонстрационные примеры

Эти файлы преподаватель может показывать на лекции. Они объясняют принцип и **не являются** стартом лабораторной или готовым решением самостоятельной части.

- [event-flow.md](event-flow.md) — авторская схема события GUI.
- [http-trace.md](http-trace.md) — разбор HTTP-запроса и ответа.
- [code-inspection.md](code-inspection.md) — пример аргументированного замечания.
- [json-valid.json](json-valid.json) и [json-broken.json](json-broken.json) — успешный и ошибочный ввод сериализатора.
- [sql-injection.md](sql-injection.md) — почему конкатенация SQL опасна и как отделяются значения.

Авторские схемы не выдаются за иллюстрации официальной документации. Для самостоятельной работы используйте [starter](../starter/README.md).
