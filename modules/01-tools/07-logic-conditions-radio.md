# 07 Логические операции условия и переключатели

**Связь с программой:** тема 2.1, строка 7, 2 часа. Подготовка к ПР 3.

**Цель:** строить условие из наблюдаемых признаков и связывать его с состоянием RadioButton.

**Результат:** студент составляет таблицу истинности, объясняет ветвление и находит неполное условие.

**Нужно знать:** переменная, сравнение, обработчик события.

**Обязательная часть:** `bool`, сравнения, `&&`, `||`, `!`, `if`, группы RadioButton. **Дополнительно:** ранний выход.

## Лекция

Логическое значение имеет два состояния: истина и ложь. Сравнения `==`, `!=`, `<`, `>`, `<=`, `>=` создают логическое значение. Операция `&&` требует истинности обоих условий, `||` — хотя бы одного, `!` меняет значение на противоположное.

Условный оператор выбирает ветвь выполнения. До записи кода полезно назвать случаи словами. Для добавления проекта: название заполнено **и** часы неотрицательны. Если хотя бы одно условие ложно, добавление не выполняется.

```csharp
bool hasName = !string.IsNullOrWhiteSpace(name);
bool hoursAreValid = hours >= 0;

if (hasName && hoursAreValid)
{
    AddProject();
}
else
{
    ShowValidationError();
}
```

Короткое замыкание означает, что правая часть `&&` не вычисляется, если левая уже ложна. Это позволяет сначала проверить объект на `null`, затем обращаться к его свойству. Порядок условий может влиять на безопасность.

RadioButton представляет выбор одного варианта из группы. На Windows Forms переключатели, помещённые в один контейнер, взаимоисключают друг друга. Две независимые группы должны находиться в разных `GroupBox` или `Panel`. Состояние читается через `Checked`. По умолчанию разумно либо выбрать безопасный вариант, либо явно требовать выбор — решение зависит от задачи.

Интерфейс не должен хранить противоречивое состояние. Если выбраны «Активный» и «Завершён» в одной смысловой группе, значит элементы сгруппированы неверно. Если кнопка действия доступна при отсутствии выбора, проверка неполна. Логика разрешения действия должна быть одна и проверяться одинаково при вводе и перед сохранением.

Типичные ошибки: использовать `&` вместо `&&`; забыть отрицание; написать несколько независимых `if`, когда нужна одна взаимоисключающая цепочка; сравнивать текст элемента вместо значения; полагаться только на выключенную кнопку и не проверять данные в обработчике.
