**Результат:** студент отличает класс, структуру и запись, создаёт экземпляр и объясняет ссылочную и значимую семантику.

## Лекция

Класс описывает состояние и поведение объектов одного вида. Объект — конкретный экземпляр. Свойства предоставляют контролируемый доступ к состоянию, методы выполняют действия. Конструктор создаёт допустимое исходное состояние.

```csharp
public sealed class ProjectItem
{
    public ProjectItem(string name, int hours)
    {
        Name = string.IsNullOrWhiteSpace(name)
            ? throw new ArgumentException("Название обязательно", nameof(name))
            : name.Trim();
        Hours = hours >= 0
            ? hours
            : throw new ArgumentOutOfRangeException(nameof(hours));
    }

    public string Name { get; }
    public int Hours { get; private set; }

    public void AddHours(int value)
    {
        if (value <= 0) throw new ArgumentOutOfRangeException(nameof(value));
        Hours += value;
    }
}
```

Класс — ссылочный тип: переменная обычно хранит ссылку на объект. Две переменные могут указывать на один экземпляр, поэтому изменение видно через обе. `struct` — значимый тип; присваивание обычно копирует значение. Структуры подходят для небольших значений с ясной семантикой, например координаты или диапазон, но большие изменяемые структуры создают неожиданные копии.

`record` предоставляет удобную модель данных со сравнением по значениям. `record class` остаётся ссылочным типом, `record struct` — значимым. Записи полезны для сообщений и снимков данных. Они не отменяют необходимость проверять значения и не обязаны быть неизменяемыми, хотя часто используются так.

Инкапсуляция означает, что объект защищает свои правила. Если `Hours` нельзя делать отрицательным, лучше не оставлять публичный произвольный `set`, а проверять в конструкторе и методах. Интерфейс формы не должен быть единственным местом проверки: объект может создаваться из JSON, БД или теста.

Типичные ошибки: класс только из публичных полей без правил; конструктор создаёт недопустимый объект; структура используется для большого изменяемого графа; сравнение классов ожидается по значению; в свойства помещают тяжёлую работу и скрытые побочные эффекты.
