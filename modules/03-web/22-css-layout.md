# 22 CSS: каскад, блоки и компоновка

**Связь с программой:** тема 2.3, строка 3, 2 часа. Подготовка к ПР 15.

**Цель:** отделить оформление от содержания и предсказуемо расположить блоки.

**Результат:** студент объясняет каскад, блочную модель, Flexbox/Grid и проверяет состояния интерфейса.

**Нужно знать:** HTML и DOM. **Обязательная часть:** селекторы, каскад, наследование, box model, классы, Flexbox. **Дополнительно:** Grid и custom properties.

## Лекция

CSS применяет правила к элементам DOM. Правило состоит из селектора и объявлений. Победившее значение определяется происхождением, важностью, специфичностью и порядком. `!important` не лечит непонятную архитектуру стилей и используется редко.

```css
:root {
  --accent: #2457a7;
  --surface: #ffffff;
}

* { box-sizing: border-box; }

.project-card {
  padding: 1rem;
  border: 1px solid #cbd5e1;
  border-radius: .5rem;
  background: var(--surface);
}
```

Блочная модель включает содержимое, внутренний отступ `padding`, рамку и внешний отступ `margin`. При `box-sizing: border-box` заданная ширина включает padding и border, что упрощает расчёт.

Flexbox размещает элементы в одном основном направлении: строке или столбце. Grid задаёт строки и столбцы двумерной сетки. Они предназначены для компоновки; абсолютное позиционирование не должно быть основой обычной страницы.

Класс описывает повторяемую роль (`.project-card`), `id` — уникальный узел, элементный селектор — общую базу. Имена вида `.blue-text` привязывают смысл к конкретному оформлению; `.validation-message` устойчивее.

Состояния `:hover`, `:focus-visible`, `:disabled` важны. Нельзя убирать обводку фокуса без равнозначной замены. Цвет не должен быть единственным носителем ошибки; добавляют текст и значок.

Ошибки: инлайновые стили в каждом элементе; фиксированная ширина шире телефона; недостаточный контраст; глобальный селектор, случайно меняющий все кнопки; отрицательные отступы вместо исправления разметки; CSS, который переставляет смысловой порядок только визуально.
