# Модульные тесты: старт ПР 13

Требование к `ProjectRules.IsNameValid`: после удаления пробелов по краям название содержит от 3 до 120 символов. `null` недопустим. Тесты используют MSTest 4.5.1 и .NET 10.

1. Откройте `Course.Tests.slnx` либо оба проекта в Visual Studio 2026.
2. Выполните `dotnet test`.
3. Начальное состояние содержит намеренную ошибку: `null` ошибочно признаётся допустимым. Один тест должен упасть.
4. Исправьте реализацию, но не тест. Повторите запуск: все исходные тесты должны пройти.
5. Самостоятельно добавьте граничные случаи 2, 3, 120 и 121 символ.

Это стартовый проект, не эталон самостоятельной части.
