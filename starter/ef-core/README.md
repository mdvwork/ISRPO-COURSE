# EF Core: старт ПР 12

Набор реализует современный вариант работы с моделью данных: EF Core 10.0.12 и SQLite. Он раскрывает идею EDM, но не воспроизводит визуальный дизайнер классического Entity Framework.

1. Установите .NET 10 SDK через Visual Studio 2026.
2. Откройте терминал в этой папке и выполните `dotnet restore`, затем `dotnet run`.
3. Ожидается создание `course.db`, двух проектов и вывод их названий.
4. Сравните таблицы с `schema.sql`. Для повторного старта удалите только свою копию `course.db` и снова выполните запуск.

Пакеты закреплены на 10.0.12. В среде сборки курса .NET 10 и эти пакеты отсутствовали, поэтому преподавателю нужно выполнить Windows-проверку перед выдачей.
