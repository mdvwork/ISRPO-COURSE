# Подготовка домашнего рабочего места

Инструкции проверены по официальной документации 13 октября 2026 года. Они рассчитаны на Windows 11 x64. Windows 10 завершила обычную поддержку; для нового учебного окружения она не рекомендуется. WPF не запускается на Linux и macOS.

## Минимальная конфигурация

- 64-разрядная Windows 11 не в S-режиме;
- 8 ГБ оперативной памяти, лучше 16 ГБ;
- не менее 30 ГБ свободного места для полного набора;
- права на установку программ;
- современный браузер и доступ в интернет для установки пакетов.

Если компьютер слабее, сначала выполните HTML, CSS и JavaScript без сборщика. Для WPF и Visual Studio договоритесь о доступе к подходящему Windows-компьютеру: телефон эту часть не заменяет.

## Visual Studio и NET

1. Откройте официальный установщик Visual Studio.
2. Выберите выпуск Community 2026.
3. В списке рабочих нагрузок отметьте **Разработка классических приложений .NET**.
4. В отдельных компонентах убедитесь, что выбран **.NET 10 SDK**.
5. После установки откройте PowerShell и выполните:

```powershell
dotnet --version
dotnet --list-sdks
```

Ожидается версия SDK `10.0.x`. Если шаблон WPF не виден, откройте Visual Studio Installer, нажмите **Изменить** и добавьте указанную рабочую нагрузку. Не выбирайте шаблон `WPF Application (.NET Framework)`, если методичка прямо не говорит об историческом варианте.

## Web без сервера

Для работ 14–17 достаточно редактора и браузера. Можно использовать Visual Studio Code, но конкретный редактор не влияет на результат. Открывайте HTML двойным щелчком или через локальный сервер. Если `fetch()` не читает локальный JSON из-за политики браузера, запустите сервер из папки проекта:

```powershell
python -m http.server 8080
```

Если Python не установлен, используйте встроенный сервер редактора или OSPanel. Затем откройте `http://localhost:8080`. Не открывайте учебный сервер для внешней сети.

## Open Server Panel PHP и MySQL

Open Server Panel работает только на поддерживаемой 64-разрядной Windows, требует NTFS и, по данным проекта, не менее 4 ГБ ОЗУ и 15 ГБ на диске.

1. Скачайте дистрибутив только с `ospanel.io` и сравните опубликованные контрольные суммы.
2. Установите в путь без кириллицы и пробелов, например `C:\OSPanel`.
3. Запустите панель, выберите PHP 8.5 и MySQL 8.4, если эти ветки присутствуют в поставке.
4. Создайте локальный домен по инструкции OSPanel или поместите проект в каталог, который панель показывает как домашний.
5. В терминале OSPanel выполните:

```powershell
php -v
mysql --version
```

Если OSPanel не содержит нужную ветку, не подменяйте её молча: сохраните вывод версий и согласуйте с преподавателем. Для работ 18–20 нужны расширения `pdo` и `pdo_mysql`; проверьте `php -m`.

## Node React и Vite

Установите Node.js 24 LTS. В PowerShell проверьте:

```powershell
node --version
npm --version
```

Для стартового React-проекта перейдите в его каталог и выполните:

```powershell
npm install
npm run dev
```

Зависимости закреплены в `package.json`. Не заменяйте версии случайными командами обновления перед сдачей. Если `npm` не найден, закройте и снова откройте терминал; затем проверьте, добавлен ли Node.js в `PATH`.

## WordPress

WordPress 7.1.3 запускается локально поверх PHP и MySQL. Официальные рекомендации требуют PHP 8.3 или новее, MySQL 8.0 или новее либо MariaDB 10.11 или новее и поддержку HTTPS. В работе используется PHP 8.5 и MySQL 8.4 LTS. Учебная установка локальная; не используйте реальную почту и реальные пароли.

## Быстрая диагностика

| Симптом | Проверка | Действие |
| --- | --- | --- |
| Нет шаблона WPF | Есть ли рабочая нагрузка .NET Desktop | Изменить установку Visual Studio |
| Проект требует другой SDK | `dotnet --list-sdks` | Установить .NET 10 SDK |
| JSON не загружается из HTML | Адрес начинается с `file://` | Запустить локальный HTTP-сервер |
| PHP сообщает `could not find driver` | `php -m` содержит `pdo_mysql` | Включить расширение в модуле PHP OSPanel |
| MySQL не подключается | Запущен ли модуль и совпадает ли порт | Проверить журнал OSPanel и параметры `config.local.php` |
| `npm` не найден | `where.exe node` и `where.exe npm` | Переустановить Node.js LTS с добавлением в PATH |
| WPF запускается, но окно пусто | Окно запуска и ошибки привязки | Проверить `StartupUri`, Output и `DataContext` |

Перед первой лабораторной создайте рабочую папку без облачной синхронизации и кириллицы в пути, например `C:\isrpo-work`. Каждый номер копируйте в отдельный каталог.
