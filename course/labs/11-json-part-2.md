# ПР 11.2. Чтение JSON и восстановление после ошибок

**Программа:** ПР 11, часть 2, 2 часа. **Цель:** загрузить данные и безопасно обработать отсутствие/повреждение файла. **Результат:** валидный JSON восстанавливает коллекцию, ошибки не уничтожают текущие данные.

**Знания:** часть 11.1, десериализация, исключения. **ПО:** Windows 11, Visual Studio 2026, .NET 10.

## Стартовое состояние и восстановление

Продолжайте 11.1. Если её нет, скопируйте [WPF-набор](../starter/wpf-projects/README.md) и используйте предоставленный `data/projects.json` как формат версии без оболочки; загрузчик должен явно поддержать выбранный формат.

## Выполнение

1. Реализуйте `LoadAsync`: при отсутствии файла вернуть пустой документ и сообщение, а не исключение пользователю.
2. Десериализуйте во временный объект. Проверьте `null`, уникальность id, имя и часы каждого элемента. Только после полной проверки замените коллекцию UI.
3. Добавьте `LoadCommand`. На успехе покажите количество, на ошибке формата — имя файла и безопасное сообщение; подробность `JsonException` можно записать в журнал.
4. Повредите копию JSON: удалите запятую. Запустите загрузку. Ожидается сообщение об ошибке и сохранение прежней коллекции.
5. Восстановите файл, добавьте неизвестное поле и загрузите. По выбранной политике оно игнорируется; зафиксируйте совместимость.

## Самостоятельная часть

Реализуйте обработку дублирующихся id: загрузка отклоняется целиком, сообщение указывает конфликтующий id. Добавьте отдельный сценарий с двумя одинаковыми id.

## Проверка и диагностика

Проверьте: файл отсутствует; пустой массив; валидная кириллица; синтаксическая ошибка; неверный диапазон; дубли id; неизвестное поле. Если данные исчезают при ошибке — коллекция очищена до проверки. Если UI зависает — синхронно читается большой файл на UI-потоке.

## Сдача и критерии

Сдайте загрузчик, минимум четыре файла-сценария и таблицу результатов. Критерии: 3 — корректная загрузка; 2 — атомарная замена коллекции; 3 — дубликаты/самостоятельный сценарий; 2 — диагностика. **Критические ошибки:** повреждённый файл стирает текущие данные; недопустимые объекты принимаются; исключение не обработано.
