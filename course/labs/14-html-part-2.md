# ПР 14.2. Доступная HTML-форма

**Программа:** ПР 14, часть 2, 2 часа. **Цель:** собрать форму с именованными полями и понятными ограничениями. **Результат:** браузер проверяет базовый ввод, подписи и сообщения доступны с клавиатуры.

**Знания:** часть 14.1, формы, HTTP. **ПО:** Windows 11, браузер, редактор. **Старт:** продолжение 14.1; если его нет, скопируйте [static-web](../starter/static-web/README.md) и добавьте форму в отдельную секцию.

## Выполнение

1. Создайте форму проекта с полями `name`, `hours`, `status`, `description`. Каждый control имеет уникальный id, `name` и постоянный `label`.
2. Задайте `required`, для имени `minlength=3 maxlength=120`, для часов `type=number min=0 max=1000`. Статусы дайте через одну группу radio с `fieldset`/`legend`.
3. Кнопке отправки задайте `type=submit`, кнопке очистки — `type=reset`. До PHP используйте `action="#"`; не вводите фиктивный серверный адрес.
4. Отправьте пустую форму и неправильные часы. Ожидается встроенная подсказка и отсутствие отправки. Затем введите корректные данные и посмотрите Form Data/адрес; значения с `name` присутствуют.
5. Пройдите форму Tab/Shift+Tab, выберите radio стрелками, увеличьте масштаб до 200%. Порядок соответствует визуальному и смысловому.

## Самостоятельная часть

Добавьте необязательную дату завершения и обязательный тип проекта (`select` минимум из трёх значений). В `report.md` опишите два правила, которые браузер не может проверить без серверной логики.

## Проверка и диагностика

Сценарии: всё пусто; имя из 2; часы -1/1001; корректная форма; только клавиатура. Если значение не отправляется — нет `name` или control disabled. Если label не активирует поле — `for` не равен id. Placeholder не считается исправлением.

## Сдача и критерии

Сдайте HTML и таблицу пяти сценариев. Критерии: 3 — корректные имена/подписи; 2 — ограничения; 3 — самостоятельные поля/анализ сервера; 2 — клавиатура. **Критические ошибки:** поле без label; обязательное значение не имеет name; форма непроходима с клавиатуры.

## Вопросы

1. Для чего нужен `name`?
2. Как связать label?
3. Зачем fieldset/legend?
4. Почему браузерной проверки недостаточно?
5. Чем submit отличается от button?
