# ПР 17. Динамический список на JavaScript

**Программа:** «Создание динамических страниц с JavaScript», 2 часа. **Цель:** отделить данные, вычисления и DOM. **Результат:** JSON загружается, проекты фильтруются и отображаются безопасно, ошибки видимы.

**Знания:** HTML/CSS, функции, массивы, события. **ПО:** браузер/DevTools, локальный web server редактора. **Старт:** [static-web](../starter/static-web/README.md). Для `fetch` не используйте `file://`.

## Выполнение

1. Запустите локальный сервер и откройте Network. `data/projects.json` должен вернуть 200 и JSON. Состояние меняется «Загрузка…» → «Найдено: 3».
2. Прочитайте `filtered`: она не меняет исходный массив. В Console проверьте пустой запрос, «кат» и «нет».
3. Прочитайте `render`: пользовательский текст назначается через `textContent`. Добавьте в копию JSON имя `<img src=x onerror=alert(1)>`; оно должно показаться текстом, код не выполняется.
4. Добавьте живую фильтрацию по событию `input` либо оставьте submit и объясните выбор. Покажите пустое состояние.
5. В DevTools включите Offline. Перезагрузите: ожидается сообщение об ошибке, подробность в Console, а не пустой экран.

## Самостоятельная часть

Добавьте выбор сортировки «по названию/по часам». Используйте копию массива (`toSorted` или `[...items].sort`), не меняйте `projects`. Сортировка должна работать вместе с фильтром.

## Проверка и диагностика

Проверьте 200, 404 (временно неверный путь), повреждённый JSON, опасную строку, пустой фильтр, сортировку. Если `fetch failed` при file URL — нужен сервер. Если список дублируется — `replaceChildren` не выполнен. Если исходный порядок изменился — применён мутирующий sort к исходному массиву.

## Сдача и критерии

Сдайте HTML/CSS/JS/JSON и шесть сценариев. Критерии: 3 — загрузка/состояния; 2 — безопасный DOM; 3 — самостоятельная сортировка; 2 — ошибки. **Критические ошибки:** пользовательская строка выполняется как HTML; ошибка сети скрыта; фильтр уничтожает данные.
