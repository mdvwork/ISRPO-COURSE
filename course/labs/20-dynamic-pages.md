# ПР 20. Динамические страницы PHP

**Программа:** «Создание динамических страниц», 2 часа. **Цель:** отделить получение данных от HTML-шаблона и безопасно вывести БД. **Результат:** список и карточка проекта формируются из MySQL, состояния 200/404/500 различаются.

**Знания:** PHP/PDO, HTML, SQL, MVC. **ПО:** Windows 11, Open Server Panel 6.5.1, PHP 8.5, MySQL 8.4. **Старт:** [php-site](../starter/php-site/README.md), `projects.php` и БД из ПР 18.

## Выполнение

1. Откройте `/projects.php`: ожидаются строки seed. Проверьте Network 200 и отсутствие SQL/пароля в HTML.
2. Вынесите функцию `findAllProjects(PDO $pdo): array` в `src/project_repository.php`. В `projects.php` остаются вызов и шаблон; SQL внутри HTML-цикла отсутствует.
3. Создайте `project.php?id=...`: проверьте id как положительное целое, выполните prepared SELECT, при отсутствии верните 404 и понятный текст.
4. Все строки из БД пропускайте через `h`, числа приводите к int. Добавьте в БД название `<b>Тест</b>` и убедитесь, что теги показаны текстом.
5. Временно остановите MySQL. Ожидается 500/общая страница и запись подробности в журнал, затем восстановите сервис.

## Самостоятельная часть

Добавьте фильтр статуса через whitelist `planned|active|done`. Репозиторий строит один из заранее разрешённых запросов/параметров; произвольный SQL-фрагмент из URL не используется. Ссылка «Все» снимает фильтр.

## Проверка и диагностика

Проверьте список, существующий/отсутствующий/неверный id, HTML в данных, каждый статус, недоступную БД. Если 404 возвращает код 200 — установите `http_response_code(404)`. Если HTML выполняется — пропущено экранирование. Если сортировка/фильтр конкатенируются — замените параметром или whitelist.

## Сдача и критерии

Сдайте PHP и таблицу минимум восьми запросов со статусами. Критерии: 3 — данные/шаблон разделены; 2 — коды/ошибки; 3 — самостоятельный whitelist-фильтр; 2 — экранирование. **Критические ошибки:** SQL в шаблонном цикле; пользовательский SQL конкатенируется; данные выполняются как HTML; 404 не различается.
