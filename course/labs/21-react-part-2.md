# ПР 21.2. React: компоненты, фильтр и сборка

**Программа:** ПР 21, часть 2, 2 часа. **Цель:** разделить интерфейс на компоненты и получить production-сборку. **Результат:** список фильтруется/сортируется, key устойчив, `npm run build` проходит.

**Знания:** часть 21.1, props/state, массивы. **ПО:** те же закреплённые версии React/Vite/Node.

## Стартовое состояние и восстановление

Продолжайте 21.1. Если она пропущена, используйте [starter React](../starter/react-projects/README.md): он уже показывает четыре состояния, затем выполните `npm install`.

## Выполнение

1. Вынесите `ProjectCard` и `ProjectList`; список получает projects через props и задаёт `key={project.id}`. Не используйте индекс.
2. Оставьте поисковую строку в state `App`. `visible` вычисляется через `useMemo` либо обычное вычисление; не храните копию отфильтрованного массива в state.
3. Добавьте сортировку имени/часов, создавая новый массив. Проверьте удаление/перестановку JSON: карточки соответствуют id.
4. Добавьте компонент `ProjectSummary`: количество и суммарные часы видимых проектов. Значения вычисляются, не синхронизируются вторым effect.
5. Выполните `npm run build`, затем `npm run preview`. В Network отсутствуют запросы к dev-модулям, интерфейс работает.

## Самостоятельная часть

Добавьте фильтр статуса с пунктом «Все» и тестовый JSON с неизвестным статусом. Неизвестное значение показывается как «Неизвестен», не ломает рендер; оно не должно молча считаться завершённым.

## Проверка и диагностика

Сценарии: пустой/частичный поиск, две сортировки, три статуса, неизвестный статус, build/preview. Если state расходится — вычисляемое значение сохранено отдельно. Если warning key — id отсутствует/повторяется. Если build падает, исправьте ошибку, не сдавайте только dev-запуск.

## Сдача и критерии

Сдайте source, public, package/lock и лог build без `node_modules/dist`. Критерии: 3 — компоненты/props; 2 — вычисления и key; 3 — самостоятельный статус; 2 — build/проверки. **Критические ошибки:** build не проходит; индекс используется как key; фильтр мутирует исходные данные; самостоятельная часть отсутствует.
