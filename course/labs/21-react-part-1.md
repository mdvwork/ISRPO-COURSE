# ПР 21.1. React: загрузка данных и состояния

**Программа:** ПР 21, часть 1, 2 часа. **Цель:** собрать React-приложение и явно представить состояния запроса. **Результат:** Vite запускается, JSON загружается, UI различает loading/error/empty/ready.

**Знания:** JavaScript, HTTP, компоненты. **ПО:** Windows 11, Node.js 24 LTS, npm, React 19.3.0, Vite 8.3.4, plugin-react 6.1.2. **Старт:** [react-projects](../starter/react-projects/README.md).

## Стартовое состояние и восстановление

Скопируйте набор, выполните `npm install`, сохраните `package-lock.json`. Не копируйте `node_modules`. Если предыдущий запуск сломан, удалите только `node_modules` своей копии и выполните `npm install` по lock-файлу; исходники восстановите из starter.

## Выполнение

1. Выполните `node --version` (24.x), `npm --version`, `npm run dev`. Откройте URL терминала; ожидаются две карточки.
2. В Network найдите `/projects.json` 200. В React DevTools/коде проследите state: `loading` до ответа, `ready` после.
3. Временно переименуйте JSON. Ожидается `error` и `role=alert`, а не бесконечная загрузка. Верните имя.
4. Замените JSON на `[]`: ожидается отдельное «Проекты не найдены». Верните данные.
5. Объясните cleanup `controller.abort()`: завершённый компонент не должен принимать поздний ответ.

## Самостоятельная часть

Добавьте кнопку «Повторить» в состоянии ошибки. Повторный запрос должен использовать новую попытку, показывать загрузку и не требовать перезагрузки страницы. Вынесите загрузку в функцию/хук без дублирования цепочки.

## Проверка и диагностика

Проверьте четыре состояния, повтор, остановку сервера и восстановление. Если белый экран — смотрите Console/terminal. Если JSON отдаётся как HTML — неверный путь. Если effect бесконечно повторяется — неверный список зависимостей. Если npm выбирает другие версии — проверьте package/lock.

## Сдача и критерии

Сдайте исходники и lock-файл без `node_modules/dist`, таблицу состояний. Критерии: 3 — установка/загрузка; 2 — четыре состояния; 3 — самостоятельный повтор; 2 — версии/диагностика. **Критические ошибки:** production-зависимость загружается с случайного CDN вместо package; ошибка скрыта; проект не запускается командой README.
