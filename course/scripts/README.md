# Проверки выпуска

Из корня `course/`:

```powershell
python scripts/validate_course.py
```

Скрипт проверяет точные количества лекций/лабораторных, обязательные разделы, относительные ссылки, JSON/XML/HTML, закреплённые версии и базовые защитные механизмы. Он не заменяет запуск WPF, PHP/MySQL, React build и WordPress на целевой Windows-среде.
