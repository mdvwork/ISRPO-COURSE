# 21 HTML: структура, семантика и формы

**Связь с программой:** тема 2.3, строка 2, 2 часа. Подготовка к ПР 14.

**Цель:** создать документ, смысл которого понятен браузеру, поиску и вспомогательным технологиям.

**Результат:** студент пишет каркас HTML, связывает подписи с полями и объясняет отправляемые данные.

**Нужно знать:** URL и HTTP. **Обязательная часть:** дерево документа, семантические элементы, атрибуты, ссылки, изображения, формы. **Дополнительно:** встроенная проверка.

## Лекция

HTML описывает структуру и смысл, а не внешний вид. Браузер разбирает разметку в дерево DOM. Вложенность должна быть корректной: дочерний элемент находится внутри родителя, а одинаковые `id` недопустимы.

```html
<!doctype html>
<html lang="ru">
<head>
  <meta charset="utf-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <title>Учебные проекты</title>
</head>
<body>
  <header><h1>Учебные проекты</h1></header>
  <main><p>Список работ группы.</p></main>
</body>
</html>
```

`header`, `nav`, `main`, `section`, `article`, `footer` сообщают роль области. Заголовки образуют иерархию, а не выбираются по размеру. У изображения содержательный `alt` описывает назначение; у декоративного — пустой `alt`.

Форма собирает именованные значения. `label` связывают с `input` через `for` и `id`. На сервер уходит значение с атрибутом `name`, а не `id`.

```html
<form method="post" action="/register.php">
  <label for="email">Электронная почта</label>
  <input id="email" name="email" type="email" required autocomplete="email">
  <button type="submit">Зарегистрироваться</button>
</form>
```

`required`, правильный `type`, `minlength`, `min` и `max` дают раннюю проверку, но их можно обойти. Сервер проверяет всё повторно. Placeholder не заменяет label: он исчезает при вводе и часто имеет слабый контраст.

Ошибки: использовать `div` вместо всех смысловых элементов; пропускать `lang` и `meta charset`; открывать ссылку в новой вкладке без причины; писать путь к локальному диску; вкладывать интерактивный элемент в другой; не задавать тип кнопки внутри формы.

## Упражнение 10 минут

Исправьте фрагмент: поле без подписи, две одинаковые `id`, кнопка без типа и изображение без `alt`. Запишите, какие данные отправятся, если у поля нет `name`.

Проверяемый результат: четыре исправления и вывод «значение без `name` не отправляется». [Ключ 21](../../teacher/EXERCISE_KEYS.md#21).
