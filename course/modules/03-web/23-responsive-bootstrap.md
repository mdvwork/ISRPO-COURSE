# 23 Адаптивная вёрстка, медиазапросы и Bootstrap

**Связь с программой:** тема 2.3, строка 4, 2 часа. Подготовка к ПР 16.

**Цель:** адаптировать содержание к доступному пространству и осознанно применить CSS-фреймворк.

**Результат:** студент строит mobile-first макет, выбирает breakpoint по содержимому и объясняет классы Bootstrap.

**Нужно знать:** CSS, блочная модель, Flexbox/Grid. **Обязательная часть:** viewport, fluid layout, media queries, Bootstrap 5.3.8. **Дополнительно:** container queries как современный контекст.

## Лекция

Адаптивный интерфейс сохраняет смысл и работоспособность при разных размерах и способах ввода. Он не равен отдельной «мобильной версии». Сначала задают простую одноколоночную основу, затем при достаточной ширине добавляют колонки — подход mobile first.

```css
.projects {
  display: grid;
  gap: 1rem;
}

@media (min-width: 48rem) {
  .projects { grid-template-columns: repeat(2, minmax(0, 1fr)); }
}
```

Точка `48rem` выбрана не по марке телефона, а потому что две карточки перестают помещаться читаемо. Проверяют не только ширину, но и увеличение текста, клавиатуру, длинные русские слова и системные настройки уменьшения движения.

Bootstrap — библиотека готовых CSS-классов и JS-компонентов. Контейнер, сетка и утилиты сокращают рутинную работу, но не отменяют HTML и доступность.

```html
<div class="container py-4">
  <div class="row g-3">
    <article class="col-12 col-md-6 col-xl-4">...</article>
  </div>
</div>
```

`col-12` занимает строку, с `md` — половину, с `xl` — треть. Стандартные breakpoints Bootstrap — соглашение фреймворка; их нужно понимать, а не подбирать классы случайно. JavaScript Bootstrap подключают только для компонентов, которым он нужен, например collapse; сетка работает на CSS.

Ошибки: скрыть важное содержимое на телефоне; сделать горизонтальную прокрутку страницы; использовать CDN без интернета в аудитории; смешать несовместимые версии CSS и JS; копировать компонент без подписей и ARIA; считать, что сетка автоматически делает форму удобной.

## Упражнение 10 минут

Для списка шести карточек задайте поведение: одна колонка до `md`, две с `md`, три с `xl`. Запишите классы и три проверки при ширине 360, 800 и 1300 пикселей.

Проверяемый результат: `col-12 col-md-6 col-xl-4`, ожидается 1/2/3 колонки. [Ключ 23](../../teacher/EXERCISE_KEYS.md#23).
