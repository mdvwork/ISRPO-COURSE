## Лекция

Windows Presentation Foundation — библиотека пользовательских интерфейсов .NET для Windows. Она объединяет окна, элементы, разметку XAML, привязку данных, стили, графику, документы и мультимедиа. WPF использует векторную систему визуализации: интерфейс описывается объектами и геометрией, а не набором заранее нарисованных пикселей.

Приложение начинается с `Application`. В `App.xaml` обычно указан `StartupUri` главного окна или обработчик запуска. Окно создаёт дерево элементов. Каждый контейнер измеряет детей и размещает их. Сначала выполняется Measure: элемент сообщает желаемый размер. Затем Arrange: родитель назначает окончательную область. Жёсткие координаты мешают этому механизму, поэтому используются панели.

Размеры задаются в независимых от устройства единицах, условно 1/96 дюйма. Масштабирование Windows и плотность экрана влияют на фактические пиксели, но логическое расположение сохраняется лучше, чем при ручном рисовании каждого пикселя.

WPF имеет логическое и визуальное дерево. Логическое отражает структуру содержимого, визуальное включает внутренние части шаблонов. События и поиск ресурсов используют деревья. Разработчику важно понимать, почему событие родительской панели может увидеть нажатие дочерней кнопки и почему стиль применяется к вложенным элементам.

Интерфейс работает в UI-потоке. Долгая операция в обработчике блокирует перерисовку и ввод. Файловые и сетевые операции выполняют асинхронно, а изменения коллекции для интерфейса возвращают в допустимый контекст. Асинхронность не делает вычисление быстрее сама по себе, а позволяет не блокировать окно во время ожидания.

WPF на современном .NET остаётся Windows-only. Наличие кроссплатформенного CLR не переносит Windows-графическую подсистему на другую ОС. Для сборки нужен Windows Desktop SDK; для запуска — Windows Desktop Runtime соответствующей версии.

Типовые ошибки: не тот `StartupUri`; исключение в конструкторе окна; бесконечный размер внутри `ScrollViewer`; тяжёлая загрузка в `Loaded`; обращение к UI из фонового потока; фиксированные размеры, обрезающие текст при масштабировании.
