# 06 Структура проекта типы ввод вывод и вычисления

**Связь с программой:** тема 2.1, строка 6, 2 часа. Подготовка к ПР 2.

**Цель:** связать файлы проекта, типы данных и преобразование ввода с проверяемым результатом.

**Результат:** студент читает структуру проекта, выбирает тип данных, проверяет ввод и объясняет вычисление.

**Нужно знать:** переменная, файл, метод.

**Обязательная часть:** проект, сборка, типы, ввод/вывод, арифметика. **Дополнительно:** nullable-типы и культура чисел.

## Лекция

Проект .NET содержит файл проекта `.csproj`, исходники `.cs`, ресурсы и настройки. Файл проекта задаёт SDK, целевую платформу и зависимости. Каталоги `bin` и `obj` создаются сборкой и не являются исходниками; их не нужно сдавать. Главный файл приложения создаёт форму или окно, а пользовательские классы хранят данные и правила.

Тип определяет множество значений и допустимые операции. `int` хранит целое число, `double` — приближённое вещественное, `decimal` удобен для денежных вычислений, `bool` — истину или ложь, `string` — текст, `DateTime` — дату и время. Нельзя выбирать тип только по внешнему виду: номер телефона — строка, потому что его не складывают и важны ведущие символы.

Текстовое поле всегда отдаёт строку. Перед вычислением строку преобразуют и проверяют. Метод `int.TryParse` возвращает признак успеха и значение без исключения для обычной ошибки пользователя.

```csharp
if (!int.TryParse(HoursTextBox.Text, out int hours) || hours < 0)
{
    ResultLabel.Text = "Введите неотрицательное целое число часов";
    return;
}

int minutes = hours * 60;
ResultLabel.Text = $"{minutes} минут";
```

Вход здесь — текст, промежуточный результат — `int`, выход — понятное сообщение. Проверка `hours < 0` относится к предметному правилу, а `TryParse` — к формату. Разделение важно: строка `abc` и число `-2` неверны по разным причинам.

Арифметические операции подчиняются приоритету. Скобки фиксируют намерение. Деление целых чисел отбрасывает дробную часть, поэтому `5 / 2` даёт `2`. Для дробного результата один операнд должен быть вещественным. Стандартные функции находятся в `Math`: `Round`, `Min`, `Max`, `Pow`, `Sqrt`. Каждая имеет область допустимых значений и правила округления.

Вывод должен позволять проверить вычисление: исходные значения, единицы измерения и формат результата. Сообщение «Готово» недостаточно, если задача — расчёт. В отладке полезно сравнить ручной контрольный пример с результатом программы.

Типовые ошибки: не проверять преобразование; путать `=` и `==`; использовать `double` для денег без причины; не учитывать пустую строку; делить целые; хранить вычисляемое значение в интерфейсе вместо модели.
