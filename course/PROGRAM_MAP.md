# Сопоставление курса с рабочей программой

Матрица воспроизводит содержание рабочей программы, а не заменяет учебный план. Часы, формы аттестации и компетенции не изменены. Нумерация лекций 01–28 введена только для навигации по репозиторию.

## Объём и результаты

| Показатель рабочей программы | Значение |

| Промежуточная аттестация | другая форма — 1(3) семестр; экзамен — 2(4) семестр, 3 часа |

Сохраняются ПК 2.2 (интеграция модулей), ПК 2.3 (отладка), ПК 2.4 (тестовые наборы и сценарии), ПК 2.5 (инспектирование кода), а также ОК 01–06 и ОК 09. Эти результаты проверяются наблюдаемыми действиями: сборкой и запуском, отладкой воспроизводимой ошибки, тестированием, анализом кода, работой с данными и сохранением версий.

## Пояснение технологий

- COM, Java и .NET Framework объясняются как разные модели компонентного выполнения. Практические работы используют современный .NET 10; это не объявляется эквивалентом COM или JVM.
- Silverlight сохранён в лекции как историческая технология. Его поддержка завершена 12 октября 2021 года; установка не требуется. Практика выполняется на WPF.
- EDM сохранён как концептуальная модель сущностей, связей и отображения. Современная реализация использует EF Core 10 и SQLite. Визуальный EDM-дизайнер классического Entity Framework не воспроизводится и не считается тождественным EF Core.
- PHP и MySQL остаются в серверном блоке. React используется только в работах 21, WordPress — только в работах 22.
