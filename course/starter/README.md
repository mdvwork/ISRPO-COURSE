# Стартовые наборы

Это заготовки, которые студент **дорабатывает** в лабораторных. Они не являются готовыми решениями самостоятельной части.

| Набор | Работы | Что уже есть |
| --- | --- | --- |
| [winforms-tools](winforms-tools/README.md) | ПР 2–5 | собираемый каркас формы, модель, намеренно ошибочная функция |
| [wpf-projects](wpf-projects/README.md) | ПР 6–11 | модели, ViewModel, команды, WPF-оболочка и JSON |
| [ef-core](ef-core/README.md) | ПР 12 | схема SQLite и консольная заготовка EF Core |
| [unit-tests](unit-tests/README.md) | ПР 13 | требования, библиотека и MSTest-проект |
| [static-web](static-web/README.md) | ПР 14–17 | HTML, CSS, JS и учебные JSON-данные |
| [php-site](php-site/README.md) | ПР 18–20 | схема MySQL и безопасный каркас PHP/PDO |
| [react-projects](react-projects/README.md) | ПР 21 | Vite/React-проект и JSON |
| [wordpress](wordpress/README.md) | ПР 22 | план содержимого и порядок восстановления |

Перед началом скопируйте нужную папку в свой каталог сдачи. Если предыдущая часть не выполнена, снова возьмите исходное состояние отсюда и следуйте разделу «Восстановление» в соответствующей методичке.
