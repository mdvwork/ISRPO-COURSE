# WinForms: старт ПР 2–5

1. Скопируйте всю папку.
2. Откройте `Course.WinForms.csproj` в Visual Studio 2026.
3. Дождитесь восстановления, выберите конфигурацию Debug и запустите `F5`.
4. Ожидается окно «Учебные проекты» с выбором статуса, кнопкой добавления и журналом.

Код интерфейса создан без Designer, чтобы все элементы и подписки были видимы в одном файле. Для ПР 2 изучается каркас, для ПР 3 — `RadioButton`, для ПР 4 — `BuggyCalculator`, для ПР 5 — динамические строки. Эталонного результата самостоятельной части здесь нет.

Требования: Windows 11, Visual Studio Community 2026, workload `.NET desktop development`, .NET 10 LTS. Свойство `CourseValidation=true` переключает только техническую проверку исходников на доступный в среде сборки .NET 8; обычная учебная сборка остаётся .NET 10.
