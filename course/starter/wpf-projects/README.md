# WPF: старт ПР 6–11

1. Скопируйте папку и откройте `Course.Wpf.csproj` в Visual Studio 2026.
2. Проверьте, что выбран .NET 10 и установлен workload `.NET desktop development`.
3. Запустите проект. Ожидаются таблица проектов, поля ввода и команды добавления/удаления.
4. `data/projects.json` копируется рядом с приложением и используется в ПР 11.

Заготовка демонстрирует уведомления и команду, но самостоятельные правила, редактирование, навигацию и обработку повреждённого JSON студент добавляет сам.

**Восстановление:** удалите рабочую копию и снова скопируйте эту папку. Не копируйте `bin/` и `obj/`.
