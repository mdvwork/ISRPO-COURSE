# WordPress: старт ПР 22

WordPress не включён в репозиторий. Используйте официальную сборку 7.1.3 и требования из `GETTING_STARTED.md`. Это исключает устаревшее ядро из учебных файлов.

Стартовая структура содержимого находится в `content-plan.csv`. В части 1 создаются локальный сайт, страницы и рубрики; в части 2 — навигация, тема, проверка и экспорт.

**Восстановление без части 1:** разверните чистый локальный WordPress, создайте страницы по CSV, выберите любую встроенную тему текущей версии. Учётные данные задайте самостоятельно и не помещайте в репозиторий.

**Сдача:** экспорт WordPress XML (`Инструменты → Экспорт`), `site-report.md` со списком версий и настроек и снимки только собственных страниц. Базу с реальными персональными данными не сдавайте.
