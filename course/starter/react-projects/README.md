# React: старт ПР 21

Версии: Node.js 24 LTS, React 19.3.0, Vite 8.3.4, `@vitejs/plugin-react` 6.1.2.

1. Скопируйте папку, выполните `npm install`, затем `npm run dev`.
2. Откройте адрес из терминала. Ожидаются карточки из `public/projects.json`.
3. После работы выполните `npm run build`; каталог `dist/` должен создаться без ошибок.
4. После первой установки сохраните созданный `package-lock.json` в сдаче.

Восстановление: заново скопируйте папку, выполните `npm install`. Не переносите `node_modules` между компьютерами и не сдавайте его.
