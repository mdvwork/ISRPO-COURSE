# Статический веб: старт ПР 14–17

Откройте папку в Visual Studio Code или Visual Studio. Для HTML/CSS допустимо открыть `index.html` в браузере. Для загрузки JSON запустите локальный сервер, например встроенный preview IDE; `file://` может блокировать `fetch`.

Начальный HTML уже семантичен, CSS задаёт базовую сетку, JS загружает `data/projects.json`. В ПР 14–17 студент последовательно добавляет форму, оформление, Bootstrap и динамическое поведение. Самостоятельные варианты в заготовку не включены.

Восстановление: повторно скопируйте папку и перенесите только собственные изменения по одному файлу.
