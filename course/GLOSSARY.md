# Словарь курса

Определения в темах остаются основными; словарь помогает быстро повторить понятие.

- **API** — согласованный способ обращения одной программы к функциям другой.
- **CMS** — система управления содержимым сайта без ручной сборки каждой страницы.
- **CRUD** — операции создания, чтения, изменения и удаления данных.
- **DNS** — система преобразования доменных имён в сетевые адреса.
- **DOM** — объектное представление HTML-документа в браузере.
- **EDM** — модель сущностей и связей данных; в классическом Entity Framework также набор средств отображения модели на хранилище.
- **HTTP** — протокол обмена запросами и ответами в Web.
- **HTTPS** — HTTP поверх защищённого TLS-соединения.
- **IDE** — интегрированная среда разработки: редактор, проект, сборка, запуск, отладка и подсказки в одном интерфейсе.
- **JSON** — текстовый формат обмена структурированными данными.
- **MVC** — разделение приложения на модель, представление и контроллер.
- **MVVM** — разделение интерфейса WPF на Model, View и ViewModel с привязками и командами.
- **ORM** — инструмент отображения таблиц и строк базы данных на объекты программы.
- **SQL-инъекция** — изменение смысла SQL-запроса через непроверенный пользовательский ввод.
- **XAML** — XML-подобный язык декларативного описания интерфейса WPF.
- **Атрибут HTML** — параметр элемента, записанный в открывающем теге.
- **Библиотека** — готовый код, функции которого вызывает приложение.
- **Верификация** — проверка соответствия результата заданным требованиям.
- **Внешний ключ** — поле, которое ссылается на ключ строки другой таблицы.
- **Привязка данных** — связь свойства интерфейса с источником данных, способная переносить изменения.
- **Исключение** — объектное описание ошибки выполнения, которое можно перехватить и обработать.
- **Класс** — описание данных и поведения объектов одного типа.
- **Компиляция** — преобразование исходного кода в форму, пригодную для выполнения или дальнейшей сборки.
- **Компонент** — заменяемая часть системы с определённым интерфейсом.
- **Маршрутизируемое событие** — событие WPF, проходящее по дереву элементов.
- **Медиазапрос** — условие CSS, применяющее стили при заданных характеристиках устройства или окна.
- **Модульный тест** — автоматическая проверка небольшой единицы поведения в изоляции от интерфейса и внешних систем.
- **Объект** — экземпляр класса с собственным состоянием.
- **Подготовленный SQL-запрос** — шаблон запроса с параметрами, отделяющий SQL-код от значений пользователя.
- **Репозиторий** — каталог проекта и его история в системе контроля версий.
- **Свойство зависимостей** — свойство WPF, значение которого участвует в привязках, стилях, анимации и наследовании.
- **Сериализация** — преобразование объекта в формат хранения или передачи, например JSON.
- **Событие** — сообщение о действии пользователя или изменении состояния.
- **Тестовый сценарий** — последовательность начальных условий, действий и ожидаемых результатов.
- **Фреймворк** — каркас, который задаёт структуру приложения и вызывает пользовательский код в предусмотренных точках.
- **Хеш пароля** — необратимое производное значение для проверки пароля без хранения его открытого текста.
