# Демонстрация: замечание инспекции

Исходный фрагмент:

```csharp
Projects.RemoveAt(SelectedRowIndex);
```

Слабое замечание: «плохой код».

Проверяемое замечание: «В команде удаления объект выбирается по видимому индексу. После сортировки индекс представления не обязан совпадать с индексом `Projects`, поэтому может удалиться другая запись. Передайте выбранный `ProjectItem` или его устойчивый `Id`; добавьте сценарий “сортировка → выбор → удаление → повторное чтение”.»

Структура: точное место → наблюдаемый риск → условие воспроизведения → конкретное исправление → проверка.
