# Публикация каталога course на GitHub

Удалённый репозиторий преподавателя не задан. Ниже подготовка нового репозитория; она ничего не публикует сама.

1. Скопируйте содержимое каталога `course/` в корень будущего репозитория.
2. Проверьте, что внутренние документы передачи из родительской папки не попали в копию.
3. В PowerShell из корня копии выполните:

```powershell
git init
git add .
git status
git commit -m "Первый выпуск курса ИСРПО"
```

4. Создайте пустой репозиторий на GitHub вручную. Не добавляйте второй README при создании.
5. Выполните команды, которые GitHub покажет для подключения `origin` и отправки текущей ветки.
6. После загрузки откройте README на GitHub и проверьте ссылки на три модуля, лабораторные и стартовые файлы.

Папка `teacher/` публична вместе с репозиторием. Если нужны закрытые варианты контроля, храните их отдельно, вне этого каталога.
