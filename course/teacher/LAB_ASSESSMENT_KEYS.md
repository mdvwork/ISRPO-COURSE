## Как принимать

1. Студент запускает результат из чистого состояния по README.
2. Преподаватель выбирает один позитивный и один негативный сценарий из методички.
3. Студент объясняет вход, ожидаемый и фактический результат.
4. Для отладки/тестов/инспекции нужны сохранённые доказательства, а не только итоговый код.
5. Если критический результат отсутствует, работа возвращается на исправление; сумма вторичных пунктов не маскирует отсутствие результата.
