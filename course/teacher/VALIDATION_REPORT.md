## Ограничения проверки

- В среде установлен только .NET SDK 8.0.423. Штатные `net10.0-windows` сборки, EF Core 10.0.12 и MSTest 4.5.1 не были восстановлены и запущены. Проверка .NET 8 подтверждает синтаксис и совместимость доступной части, но не заменяет целевую .NET 10 проверку.
- PHP и MySQL отсутствуют; `php -l`, импорт schema/seed, регистрация, сессия и реальные SQL-сценарии не запускались. Код проверен структурно.
- Node.js доступен, но npm отсутствует. Офлайн pnpm не нашёл метаданные `@vitejs/plugin-react@6.1.2`; сетевой повтор завершился SSL-ошибкой реестра. Поэтому `npm install`, Vite dev server и production build не подтверждены.
- WordPress и Open Server Panel не установлены; работы 22 и конкретные модули OSPanel требуют чистого Windows-прогона.
- Рендер исходного DOCX через стандартный скрипт документов не выполнен: в среде отсутствует `soffice.exe`; дополнительно временный каталог вернул ошибку очистки. Содержание прочитано напрямую, но визуальная верстка DOCX не проверена.
- Интерфейсы WinForms/WPF не проходили ручную визуальную проверку, клавиатурный маршрут и масштабирование. Краткий smoke start не заменяет это.
- Внешние ссылки и версии проверены по официальным первичным страницам 13 октября 2026 года, но доступность из сети колледжа не проверена.
