# Решения первого выпуска

Дата фиксации: 13 октября 2026 года.

1. **Структура.** 28 лекционных строк оформлены отдельными файлами с навигационными номерами 01–28. Все 29 практических занятий сохранены с исходными номерами 01–22 и суффиксами частей.
2. **Формат занятия.** Лекция и упражнение рассчитаны на аудиторию без компьютеров; лабораторная — на самостоятельную домашнюю работу. Это организационная реализация требования преподавателя, а не изменение часов программы.
3. **Единый контекст.** Примеры используют каталог учебных проектов. Это помогает связывать интерфейс, данные, JSON, БД и Web, но студент не обязан разрабатывать один продукт весь курс.
4. **Версии.** Основная Windows-линия — Visual Studio 2026 и .NET 10 LTS. Выбор основан на поддерживаемой LTS-ветке на дату выпуска. Проекты не переводятся на .NET Framework, кроме исторического сравнения.
5. **Silverlight.** Тема сохранена исторически; установка и запуск не назначаются, потому что поддержка завершена в 2021 году.
6. **EDM.** Понятия сущности, связи и отображения сохранены. Практическая реализация использует EF Core 10.0.12 с SQLite. Это современная реализация сходной задачи, но не полная замена визуального EDM-дизайнера классического Entity Framework.
7. **Web-стек.** PHP 8.5 и MySQL 8.4 LTS сохраняют стек программы. Open Server Panel 6.5.1 выбран как актуальная Windows-среда из программы. React 19.3 и WordPress 7.1.3 используются только в соответствующих работах.
8. **Безопасность.** Регистрация использует `password_hash`, вход — `password_verify`, БД — PDO с параметрами, сессия регенерируется, формы изменения состояния защищаются CSRF-токеном. Открытые пароли и SQL-конкатенация не допускаются.
9. **Критерии.** Критерии в лабораторных — проект критериев этого выпуска. Утверждённые преподавателем баллы и сроки не выдумывались.
10. **Git.** В отчётах требуется зафиксировать версию и проверки; локальный Git рекомендуется. Отдельная работа программы не переименована в Git-работу.
11. **Публичность.** `teacher/` считается открытым каталогом. В нём нет закрытых экзаменационных вариантов.
12. **Изображения.** Скриншоты интерфейсов не генерировались. Действия объясняются текстом; студент прикладывает только собственные снимки результата, если это нужно для проверки.
13. **Техническая сборка.** Обычная цель WinForms/WPF — .NET 10. Свойство MSBuild `CourseValidation=true` временно переключает проекты без внешних пакетов на .NET 8, установленный в среде сборки, и используется только для проверки синтаксиса/старта; это не версия, назначенная студентам.
14. **Исходники и эталоны.** `starter/` содержит дорабатываемые заготовки, `examples/` — демонстрации принципа, `teacher/` — публичные ориентиры. Готового решения самостоятельных вариантов в starter нет.
15. **Восстановление частей.** Каждая вторая часть многочастной работы допускает чистый starter и описывает минимальное восстановление, поэтому пропуск первой части не требует чужой готовой работы.
