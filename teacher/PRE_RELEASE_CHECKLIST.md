# Проверка преподавателем перед выдачей

- [ ] Сверить часы, формулировки тем, аттестацию и компетенции с действующим локальным экземпляром рабочей программы.
- [ ] Утвердить или изменить проектные критерии оценивания; добавить реальные сроки только после решения преподавателя.
- [ ] На учебном Windows 11 выполнить Visual Studio 2026/.NET 10: ПР 1–13, включая WPF, EF Core restore и MSTest.
- [ ] В Open Server Panel 6.5.1 выполнить чистую установку MySQL-схемы и все сценарии ПР 18–20.
- [ ] Выполнить `npm install`, `npm run dev`, `npm run build` на разрешённой сети для ПР 21.
- [ ] Развернуть официальный WordPress 7.1.3, проверить импорт XML и ограничения экспорта.
- [ ] Проверить доступность внешних официальных ссылок в `SOURCES.md` из сети колледжа.
- [ ] Решить, выдаётся ли весь публичный `teacher/` сразу или по этапам; не считать его защищённым.
- [ ] Проверить, что политика колледжа допускает локальные учётные данные и снимки без персональных данных.
- [ ] Создать GitHub-репозиторий по инструкции только после выбора владельца/видимости; заменить никаких фиктивных URL не требуется.
