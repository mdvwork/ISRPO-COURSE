# ПР 5. Динамические элементы управления

**Программа:** «Работа с динамическими объектами», 2 часа. **Цель:** создавать и удалять элементы во время выполнения, сохраняя связь с данными. **Результат:** строки UI создаются по модели, удаляется выбранный объект, обработчики не путают элементы.

**Знания:** классы, события, область видимости, `Tag`. **ПО:** Windows 11, Visual Studio 2026, .NET 10. **Старт:** [winforms-tools](../starter/winforms-tools/README.md).

## Выполнение

1. Запустите и добавьте два проекта. Через debugger проверьте: у каждой панели `Tag` содержит свой `ProjectItem`, а не текст.
2. Нажмите «Удалить» у первой строки. Ожидается удаление только её панели. Объясните, почему lambda захватывает локальную переменную `row` конкретного вызова.
3. Создайте поле `List<ProjectItem> _projects`. При добавлении помещайте модель и в список, при удалении — удаляйте модель из списка и панель из Controls. UI и данные должны иметь одинаковое количество.
4. Вынесите создание строки в `CreateProjectRow(ProjectItem project)`. Метод возвращает `Control`, а добавление в контейнер остаётся в обработчике.
5. После каждого действия показывайте `Данных: N; строк: M`. Проверьте последовательность добавить/добавить/удалить; значения должны быть `1/1`, `2/2`, `1/1`.

## Самостоятельная часть

Добавьте динамическую кнопку «Перевести в работу» только для запланированных проектов. Она изменяет соответствующую модель и текст строки, затем исчезает или становится недоступной. Не ищите объект по позиции элемента.

## Проверка и диагностика

Сценарии: удаление первой/последней строки; два одинаковых названия с разными id; перевод статуса; десять добавлений. Если удаляется не тот объект — используется индекс или общая переменная. Если данные остаются — удалён только Control. Если событие срабатывает дважды — подписка выполнена повторно.

## Сдача и критерии

Сдайте проект и таблицу сценариев. Критерии: 3 — синхронность модели/UI; 2 — выделенный фабричный метод; 3 — самостоятельная команда по id/объекту; 2 — негативные проверки. **Критические ошибки:** UI и модель расходятся; удаляется неправильная строка; динамический элемент не имеет рабочего обработчика.
