# ПР 11.1. Сериализация и сохранение JSON

**Программа:** ПР 11, часть 1, 2 часа. **Цель:** сохранить коллекцию в переносимом формате. **Результат:** команда записывает валидный UTF-8 JSON по известному пути, повторный запуск не повреждает файл.

**Знания:** MVVM, коллекции, файл, исключение. **ПО:** Windows 11, Visual Studio 2026, .NET 10, `System.Text.Json`. **Старт:** результат ПР 10.2 или [WPF-набор](../starter/wpf-projects/README.md) с `data/projects.json`.

## Выполнение

1. Добавьте `ProjectStorage` вне View. Передавайте ему полный путь в конструкторе; путь строится от `AppContext.BaseDirectory/data/projects.json`.
2. Реализуйте сохранение через `JsonSerializer.SerializeAsync` с `WriteIndented = true`. Создайте каталог через `Directory.CreateDirectory`.
3. Пишите сначала во временный файл `projects.json.tmp`, затем заменяйте целевой. Назначение — не оставить половину JSON при сбое записи.
4. Подключите `SaveCommand`, дождитесь async-операции, покажите точный путь и количество сохранённых объектов. Не блокируйте UI через `.Result`.
5. Откройте JSON в редакторе, проверьте кодировку, массив, имена свойств и соответствие количеству в UI.

## Самостоятельная часть

Добавьте поле `savedAtUtc` и номер формата в корневый объект-документ, а не в каждый проект. Обоснуйте, зачем метаданные отделены от элементов.

## Проверка и диагностика

Проверьте пустую коллекцию, кириллицу, 20 объектов, повторное сохранение, недоступный путь (в тестовой копии). Если сохраняется старый набор — сериализуется копия или команда не awaited. Если JSON содержит технические свойства — задайте DTO/атрибуты. Если файл в неожиданном месте — выведите абсолютный путь.

## Сдача и критерии

Сдайте проект, созданный JSON и таблицу проверок. Критерии: 3 — валидная сериализация; 2 — безопасная запись; 3 — самостоятельная оболочка/метаданные; 2 — ошибки/путь. **Критические ошибки:** файл не парсится; UI сообщает успех после неудачной записи; JSON вручную собирается конкатенацией.
