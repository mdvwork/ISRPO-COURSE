# ПР 16. Адаптивная страница с Bootstrap

**Программа:** «Создание страниц с Bootstrap», 2 часа. **Цель:** применить сетку и компоненты Bootstrap осознанно. **Результат:** макет 1/2/3 колонки работает на трёх ширинах, версии CSS/JS согласованы.

**Знания:** HTML/CSS, адаптивность. **ПО:** браузер, редактор, Bootstrap 5.3.8. **Старт:** копия результата ПР 15. Для офлайн-работы скачайте официальные файлы 5.3.8 заранее; для сети можно использовать зафиксированные официальные CDN-ссылки с integrity.

## Выполнение

1. Подключите Bootstrap 5.3.8. В Network проверьте успешную загрузку и одну версию. Свой `style.css` подключите после Bootstrap для ограниченных дополнений.
2. Оберните основное содержимое в `container`. Карточки разместите `row g-3`, каждая — `col-12 col-md-6 col-xl-4`.
3. Форме примените `form-label`, `form-control`, `form-select`, кнопке — подходящие классы. Не удаляйте label.
4. Добавьте navbar/collapse только по официальному примеру. Если используется collapse, подключите bundle JS той же версии; сетка сама JS не требует.
5. В Device Toolbar проверьте 360, 800, 1300 px: ожидается 1, 2, 3 колонки; навигация остаётся доступной.

## Самостоятельная часть

Добавьте компонент alert для результата формы и badge для статуса проектов. Состояние должно читаться текстом. Переопределите не более трёх свойств в собственном CSS и объясните каждое.

## Проверка и диагностика

Отключите сеть: если выбрали CDN, зафиксируйте, что страница без локальной копии не оформлена; приложите план офлайн. Если collapse не работает — проверьте bundle и `data-bs-*`. Если три колонки появились слишком рано — классы стоят не на дочерних элементах row.

## Сдача и критерии

Сдайте файлы/ссылки версии и таблицу трёх ширин. Критерии: 3 — сетка; 2 — корректное подключение; 3 — самостоятельные компоненты; 2 — офлайн/доступность. **Критические ошибки:** смешаны версии; важный контент скрыт; разметка Bootstrap нарушает подписи формы.
