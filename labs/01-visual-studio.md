# ПР 1. Подготовка Visual Studio

**Программа:** «Работа в среде Visual Studio», 2 часа. **Цель:** подготовить воспроизводимое рабочее место. **Результат:** новый проект собирается и запускается, версия среды и структура решения зафиксированы.

**Нужно знать:** файл, папка, программа. **ПО:** Windows 11 x64, Visual Studio Community 2026, workload `.NET desktop development`, .NET 10 LTS, Git. Компьютер нужен; телефон не заменяет работу.

## Подготовка и исходники

Установите компоненты по [GETTING_STARTED](../GETTING_STARTED.md). Стартовые файлы не нужны: проект создаётся студентом. Освободите путь без кириллицы и облачной синхронизации, например `C:\Study\ISRPO\Lab01`.

## Выполнение

1. В Visual Studio откройте **Help → About**. Запишите выпуск Visual Studio и найденный .NET SDK. Ожидается Visual Studio 2026 и SDK 10.x; проверка — эти сведения есть в `environment.md`.
2. Выберите **Create a new project → Console App**, язык C#, имя `Lab01.Environment`, framework `.NET 10.0`. Сохраните решение в своей папке. Ожидается `Lab01.Environment.csproj` и `Program.cs`.
3. В `Program.cs` замените вывод на:

   ```csharp
   Console.WriteLine($"Среда готова: {Environment.Version}");
   ```

   Назначение: получить наблюдаемый результат и версию runtime.
4. Выполните **Build → Build Solution**, затем `Ctrl+F5`. Ожидается строка `Среда готова:` без ошибок. Проверьте вкладку Output и код возврата.
5. В терминале решения выполните `git init`, `git status`. Создайте `.gitignore` шаблоном Visual Studio или скопируйте правило из корня курса. Не добавляйте `bin/` и `obj/`.
6. Намеренно удалите `;`, соберите, выпишите файл/строку/сообщение компилятора, верните символ и снова добейтесь успешной сборки.

## Самостоятельная часть

Создайте второй проект `Lab01.SystemInfo` в том же решении. Выведите имя ОС через `Environment.OSVersion` и путь текущего каталога. Это не копия примера: проверяется решение с двумя проектами и выбор запускаемого проекта.

## Проверка и диагностика

Проверьте: оба проекта собираются; каждый можно назначить Startup Project; `git status` не показывает `bin/obj`; после чистой сборки вывод повторяется. Если .NET 10 отсутствует — откройте Visual Studio Installer → Modify → Individual components и добавьте SDK. Если шаблона нет — проверьте workload. Если путь недоступен — перенесите решение в локальную папку.

## Сдача и критерии

Сдайте решение без `bin/obj`, `environment.md` и `report.md` по [правилам](../SUBMISSION.md). Проектные критерии: 4 — два запускаемых проекта; 2 — зафиксированные версии и ошибка; 2 — корректная структура/Git; 2 — объяснение результата. **Критические ошибки:** решение не собирается; нет самостоятельного проекта; заявленный запуск не подтверждён выводом.
