# ПР 7. Создание представлений по моделям

**Программа:** «Создание представлений по моделям», 2 часа. **Цель:** показать модель через WPF-привязку без ручного копирования значений. **Результат:** DataGrid и карточка выбранного проекта обновляются из одной модели.

**Знания:** XAML, модель, DataContext, binding. **ПО:** Windows 11, Visual Studio 2026, .NET 10/WPF. **Старт:** [wpf-projects](../starter/wpf-projects/README.md); если ПР 6 есть, перенесите только проверенную модель.

## Выполнение

1. Запустите старт. Через Live Visual Tree или debugger убедитесь, что `DataContext` — `MainViewModel`, а `ItemsSource` — `Projects`.
2. Добавьте справа `Border` с `TextBlock`, привязанными к `SelectedProject.Name` и `SelectedProject.Hours`. До выбора покажите текст «Выберите проект» через отдельный элемент/триггер.
3. Сделайте столбцы явными: код, название, часы, статус. Заголовки пользовательские, технические свойства не выводятся.
4. Добавьте ресурс `ProjectCardStyle` для отступа, рамки и фона; примените к карточке. Стиль не должен менять данные.
5. Измените название выбранного объекта в debugger или временной кнопкой. Если модель реализует `INotifyPropertyChanged`, таблица и карточка должны обновиться одновременно.

## Самостоятельная часть

Создайте `DataTemplate` для задачи: название, текстовое состояние и доступная отметка. Покажите список задач выбранного проекта. Не копируйте шаблон карточки проекта; свойства и смысл отличаются.

## Проверка и диагностика

Проверьте: нет выбора; выбран проект; изменено свойство; коллекция пуста; длинное название. Ошибки binding смотрите в Output. Если интерфейс пуст — проверьте DataContext и имя свойства. Если обновляется только после перезапуска — отсутствует уведомление. Если длинный текст ломает окно — добавьте перенос/ограничение.

## Сдача и критерии

Сдайте XAML, связанные модели и пять сценариев. Критерии: 3 — корректные привязки; 2 — пустое состояние; 3 — самостоятельный шаблон задач; 2 — доступность/объяснение. **Критические ошибки:** значения жестко вписаны вместо binding; ошибки привязки в Output; выбранный объект не соответствует карточке.
