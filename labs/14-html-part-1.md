# ПР 14.1. Семантическая HTML-страница

**Программа:** ПР 14, часть 1, 2 часа. **Цель:** собрать корректную структуру страницы без зависимости от оформления. **Результат:** документ имеет язык, метаданные, иерархию заголовков, навигацию и содержательные карточки.

**Знания:** URL, HTML-элемент/атрибут. **ПО:** Windows 11, актуальный Edge/Chrome, редактор кода. **Старт:** копия [static-web](../starter/static-web/README.md); на этой части JavaScript можно временно отключить.

## Выполнение

1. Откройте `index.html` и DevTools → Elements. Проверьте doctype, `lang=ru`, UTF-8, viewport, title. Исправьте отсутствующее; перезагрузите без ошибок парсинга.
2. Добавьте `nav` со ссылками-якорями «Проекты», «Как работать», «Контакты». Создайте соответствующие секции с уникальными id.
3. В секции проектов вручную оставьте две учебные `article` (до JS): заголовок, описание, часы, статус. Заголовки идут `h1 → h2 → h3` по структуре, не по размеру.
4. Добавьте изображение или SVG-иконку только если она содержательна; задайте точный `alt`. Для декоративной задайте пустой `alt`. Не генерируйте скриншот интерфейса.
5. Отключите CSS в DevTools. Порядок чтения и смысл должны сохраниться. Пройдите Tab: ссылки доступны и имеют понятный текст.

## Самостоятельная часть

Добавьте секцию «Критерии готовности проекта» в виде подходящего списка и карточку собственного учебного проекта с другим содержанием. Объясните выбор `ol` или `ul`.

## Проверка и диагностика

Проверьте HTML валидатором IDE, уникальность id поиском, все якоря, масштаб 200% и отсутствие CSS. Если якорь не работает — id не совпадает. Если кириллица искажена — файл/мета не UTF-8. Если heading level пропущен только ради размера — исправьте структуру, размер задаст CSS.

## Сдача и критерии

Сдайте HTML и `report.md` с деревом разделов. Критерии: 3 — каркас/семантика; 2 — навигация/доступность; 3 — самостоятельная секция/карточка; 2 — проверки. **Критические ошибки:** документ не открывается; отсутствует основное содержимое; смысл зависит от CSS; самостоятельная часть копирует пример.
