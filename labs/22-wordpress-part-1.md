# ПР 22.1. Локальная установка и структура WordPress

**Программа:** ПР 22, часть 1, 2 часа. **Цель:** развернуть локальную CMS и спроектировать структуру содержания. **Результат:** WordPress 7.1.3 установлен локально, созданы страницы/записи без лишних плагинов.

**Знания:** CMS, PHP/MySQL, страница/запись. **ПО:** Windows 11, Open Server Panel 6.5.1, WordPress 7.1.3 из официального источника, PHP 8.3+ (в курсе 8.5), MySQL 8.4. **Старт:** [wordpress](../starter/wordpress/README.md), `content-plan.csv`.

## Установка и исходное состояние

Скачайте официальный архив WordPress, проверьте версию, распакуйте в отдельный локальный домен. Создайте отдельную пустую БД. Не используйте реальные персональные данные/пароль от других сервисов. Если часть 1 пропущена, README starter описывает восстановление с нуля.

## Выполнение

1. Пройдите установщик: адрес локальной БД, отдельный администратор, уникальный учебный пароль. `wp-config.php` не публикуйте.
2. В **Инструменты/Состояние сайта** и **Обновления** зафиксируйте версии WordPress/PHP/MySQL. Ожидается 7.1.3/8.5/8.4.x в этом выпуске.
3. Удалите демо-запись/страницу, но не системные файлы. По `content-plan.csv` создайте Главную, Проекты, О курсе и две записи.
4. В **Настройки → Чтение** назначьте статическую главную. Включите человекочитаемые постоянные ссылки и проверьте каждый URL.
5. Выберите встроенную тему, проверьте сайт и административную часть. Не устанавливайте плагины без функциональной необходимости.

## Самостоятельная часть

Создайте собственную рубрику и третью запись о другом учебном проекте: задача, результат, технология, одно ограничение. Добавьте корректный excerpt и featured image только из разрешённого собственного/свободного источника с alt.

## Проверка и диагностика

Проверьте front/admin, 5+ материалов, главную, постоянные ссылки, мобильную ширину, версию. Белая страница: смотрите журнал PHP, не включайте подробные ошибки публично. Ошибка БД: проверьте локальные реквизиты. Не исправляйте ядро WordPress вручную.

## Сдача и критерии

Сдайте WordPress XML-экспорт и `site-report.md`; не сдавайте пароли/полный config. Критерии: 3 — установка/версии; 2 — структура; 3 — самостоятельная рубрика/запись; 2 — безопасность/проверки. **Критические ошибки:** сайт не открывается; использована неизвестная устаревшая сборка; в сдаче секреты; самостоятельного содержания нет.
