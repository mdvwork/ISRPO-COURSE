# Инструментальные средства разработки программного обеспечения

Первый выпуск курса МДК.02.02 для специальности 09.02.07. Курс сохраняет темы и номера практических работ рабочей программы. В аудитории изучаются теория и короткие задания без компьютера; лабораторные выполняются дома на компьютере по пошаговым методичкам.

## Как работать с курсом

1. Прочитайте [подготовку рабочего места](GETTING_STARTED.md).
2. Откройте тему по порядку в разделе [Лекции](#лекции).
3. Выполните указанное в конце темы аудиторное упражнение на бумаге или телефоне.
4. Дома выполните связанную лабораторную из [каталога работ](labs/README.md).
5. Перед отправкой проверьте [правила сдачи](SUBMISSION.md).

Если вы пропустили предыдущую часть многочастной работы, используйте стартовое состояние, указанное в её методичке. Не берите готовый пример за собственную работу: демонстрации, стартовые заготовки и эталонные ориентиры имеют разные назначения.

## Важные границы

- WPF выполняется только на Windows. Silverlight рассматривается исторически и не устанавливается.
- Лабораторные с сервером выполняются локально. Учебный сервер нельзя открывать в интернет.
- Папка `teacher/` не является закрытой: в публичном репозитории её видят студенты. В ней находятся ориентиры проверки, а не секретные экзаменационные ответы.
- В курсе нет утверждённых преподавателем дедлайнов и общей балльной шкалы. Критерии лабораторных — проект критериев этого выпуска.
